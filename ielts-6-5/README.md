# Путь к IELTS 6.5

Приложение для ежедневной подготовки к IELTS Academic 6.5 (B1 → C1) к августу 2027 года для поступления на PhD Coaching & Leadership.

**Открыть приложение:** https://galbagdat.github.io/Galiya-Bagdat/ielts-6-5/

| Раздел | Что внутри |
|---|---|
| Сегодня | Утреннее занятие на 30 минут из 5 блоков |
| Слова | Слова дня и интервальное повторение |
| Грамматика | 17 тем, правила на русском |
| Речь | IELTS Speaking Part 1–3 и интервью |
| Перевод | RU → EN |
| Чтение | True / False / Not Given |
| Этапы и тесты | 5 уровней с разблокировкой |

Прогресс хранится в браузере (localStorage). Подробности есть в [PRD.md](PRD.md).
